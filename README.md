# 🤖 AI Security

### AI Security | LLM Security | AI Threat Modeling | AI Red Teaming

This repository documents my hands-on learning and practical work in **AI Security**, with a focus on securing AI applications, Large Language Models (LLMs), RAG systems, AI agents, and the surrounding infrastructure.

The goal is to understand how AI systems can be attacked, how those risks can be identified, and how effective security controls can be designed.
